## Cocatrel Dashboard

Esse projeto será a implementação do dashboard de controle de vendas de sacas de café da Cocatrel.

Atuando como uma coperativa de cafeicultores, a Cocatrel tem a necessidade de um dashboard que possa controlar as vendas de sacas de café, bem como o controle de estoque e a previsão de vendas.

## 🚀 Sobre o projeto

Será implementado um aplicativo em flutter para que os agricultores possam fazer a venda de suas sacas de café, bem como o controle de estoque e a previsão de vendas.

## 🛠️ Built with

- 📱 Flutter
